# Plan: Download ARK Item Icons & Update Markdown

## Goal
1. Download 256px item icons from ark.wiki.gg for all 1624 items in `docs/asa-itemsids.md`
2. Save icons to `D:\golang\asa-server\icon\items\` using class name as filename (e.g., `PrimalItemResource_SubstrateAbsorbent_C.png`)
3. Add an `Icon` column to the markdown tables

## Icon URL Pattern (discovered)
- Item icons on ark.wiki.gg follow this pattern:
  ```
  https://ark.wiki.gg/images/thumb/{ItemName}.png/256px-{ItemName}.png
  ```
- Where `{ItemName}` = item display name with spaces → underscores (e.g., "Absorbent Substrate" → `Absorbent_Substrate`)
- **Key**: The icon file name is based on the **item display name**, NOT the class name

## Implementation Steps

### Step 1: Create a Python script to parse MD and download icons
Write a Python script (`tools/download_icons.py`) that:
1. Parses `docs/asa-itemsids.md` to extract: item display name, class name
2. Constructs icon URL from display name: `https://ark.wiki.gg/images/thumb/{name}.png/256px-{name}.png`
3. Downloads each icon via HTTP GET to `icon/items/{ClassName}.png`
4. Uses `concurrent.futures.ThreadPoolExecutor` for concurrent downloads (10 workers)
5. Skips items that already have downloaded icons (resume support)
6. Reports progress and failures

### Step 2: Update the markdown file
After downloading icons, update `docs/asa-itemsids.md`:
- Add `Icon` column to each table header: `| Name | Stack Size | Item ID | Class Name | Blueprint Path | Icon |`
- Add icon cell to each row: `| ![](icon/items/{ClassName}.png) |`
- Icon path uses relative path from `docs/` directory

### Step 3: Verification
- Check that icons are downloaded to `icon/items/`
- Verify MD file has icon column
- Spot-check a few icons visually

## Key Files
