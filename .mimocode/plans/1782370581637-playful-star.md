# Plan: 生成 download_creature_icons.js

## 目标

创建 `D:\golang\asa-server\scripts\download_creature_icons.js`，在 Chrome DevTools Console 中执行。

## 流程

1. `showOpenFilePicker()` → 用户选择 `asa-creatureids.md`
2. 正则解析 markdown，提取去重后的 256px 图标 URL（287 个）
3. `showDirectoryPicker()` → 用户选择 `icon/creature/` 目录
4. fetch 批量下载（5 并发, 200ms 间隔），通过 FileSystemWritableFileStream **直接写入**目标目录
5. 生成更新后的 markdown（图标路径替换为 `../icon/creature/{filename}`），同样通过 FileSystemWritableFileStream 写入到 md 同级目录

## 关键点

- 使用 File System Access API 直接写文件，**不触发浏览器下载**
- 单文件自包含，无外部依赖
- 进度条 + 状态显示 + 失败列表汇报

## 输出

- `D:\golang\asa-server\scripts\download_creature_icons.js` — 唯一产物

## 验证

1. Chrome 打开 `https://ark.wiki.gg/wiki/Creature_IDs`
2. DevTools Console 粘贴脚本执行
3. 选择 md 文件 → 选择目标目录 → 等待完成
4. 确认 `icon/creature/` 下有 287 个 png
