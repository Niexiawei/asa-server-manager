## 执行策略

### 步骤 1：提取文档中的翻译映射

编写脚本/手动从三个文档提取 `英文名 → 中文名` 的映射关系：
- `asa-creatureids.md`: 提取 Name + 名称（中文）列
- `asa-itemsids.md`: 提取 Name + Chinese Name 列  
- `asa-engrams.md`: 提取 Item + 名称（中文）列

### 步骤 2：直接匹配填充

将提取的映射与 custom.json 中的空值条目进行匹配，直接填入翻译。

### 步骤 3：使用 translate_translate MCP 批量翻译剩余条目

将剩余未翻译的条目按类别分组，使用 `translate_translate` MCP（Google 渠道）批量翻译，直接写入 custom.json。

**分批策略：**
- 每批 10-15 个条目，避免单次翻译过多
- 按类别分组翻译以保持术语一致性
- 翻译完一批立即用 edit 工具更新文件

**分组计划：**
1. Swim Skins 组（~60 个）：统一模式 "XXX Swim Bottom/Top Skin" → "XXX 泳裤/泳衣皮肤"
2. Costume/Hat Skins 组（~80 个）：节日主题 + 恐龙主题皮肤
3. Emotes 组（~15 个）：动作名称
4. Shirt Skins 组（~20 个）：XXX-Print Shirt Skin → "XXX 印花衬衫皮肤"
5. Sweater Skins 组（~11 个）：Ugly XXX Sweater Skin → "丑陋 XXX 毛衣皮肤"
6. Boss/Trophy 组（~20 个）：Boss 名 + Trophy
7. 新生物组（~30 个）：Abyssal/Atlantis 生物名
8. 新物品组（~20 个）：新鞍具/新装备
9. Recipes 组（~20 个）：食物/配方名称
10. 其他杂项（~30 个）

### 步骤 4：验证

- 检查 custom.json 格式正确（有效 JSON）
- 确认所有条目均有非空翻译值
