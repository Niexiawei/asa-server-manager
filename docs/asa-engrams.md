## 使用说明

### 印痕系统概述

- **印痕点数 (EP)**: 每次升级获得印痕点数，用于解锁印痕
- **解锁等级**: 达到指定等级才能学习该印痕
- **前置印痕**: 部分印痕需要先学习其他印痕才能解锁
- **等级 1 印痕**: 自动解锁，无需花费点数

### 服务器配置命令

```
# 解锁所有印痕
admincheat GiveEngrams

# 给予印痕点数
admincheat GiveEngramPoints <数量>

# 重置印痕（需要重新学习）
admincheat ResetEngrams
```

2. **DLC 印痕**: 部分 DLC 印痕在其他地图也可学习
3. **Tek 印痕**: 必须通过击败 Boss 解锁
4. **模组印痕**: 服务器可通过配置启用/禁用特定印痕
5. **印痕重置**: 使用 `admincheat ResetEngrams` 可重置所有已学习印痕
